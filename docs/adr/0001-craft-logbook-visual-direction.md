# Craft Logbook product and visual contract

The portfolio is a **showcase-heavy Craft Logbook**: **Home** (short identity strip + dense numbered work-index, not cards), **Case Studies** (sticky/side **Capsule** meta-rail with alternating short text + artifact-first **Showcase** body), and **Resume** (catalog-owned credentials skim: shared bio, Experience, Case Study projections as Projects, Skills grouped into a few labelled bands, Languages, degree-only Education, plus a PDF download that is the same facts in a plain presentation; see ADR-0002). Contact lives in chrome (Email, Threads, X); location is Resume-only. There is no Writing index, dedicated contact page, About surface, or `/about` route.

**Why this shape:** Editorial / magazine and long-form essay directions over-weight writing. A personal app-shell is useful navigation but secondary to Craft Logbook tone. Dark-as-identity and purple-glow SaaS aesthetics read as costume. Light neutrals are the authored default; the same semantic tokens adapt when the OS prefers dark (`prefers-color-scheme`), with no user theme toggle and no dark-as-brand presentation. Geist Sans + Geist Mono, a low-chroma teal accent for meaning only (links, focus, interactive states, not identity washes), sparse UI motion, and artifact-first Showcases keep the site reading as developer-built. No scroll theatre; shared/view transitions are optional, not identity. Few Case Studies (about two to three): deep, not a large gallery; hire-first Capsules with peer depth below. Resume stays credentials, not a second proof surface and not a thin bio-only page. Skills are grouped into labelled bands rather than one curated line, so breadth beyond the published Case Studies stays visible without reading as a laundry list or spilling onto a second PDF page.

See also: `CONTEXT.md`; ADR-0003 for the copy voice.
