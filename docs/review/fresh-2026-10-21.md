## Key findings (settled)

- **P01 P2 Wrong** - [scripts/resume-pdf.ts:10-18](../../scripts/resume-pdf.ts) replaces PDF metadata with different-length strings and `buildResumePdf:32` writes these modified bytes as the public download. PDF xref entries are byte offsets ([Adobe PDF reference 3.4](https://www.adobe.com/go/pdfreference)) and must remain correct. Independent read of the committed bytes: declared `startxref=22191`, actual xref offset `22179` - off by 12 bytes ([pdf-structure-evidence.json](fresh-2026-10-21/pdf-structure-evidence.json)). Strict readers may reject or repair the file; no claim every viewer fails. The existing regex page count and Linux byte-equality checks pass over structurally broken output and do not prove validity.
- **P02 P2 Wrong** - ADR0003 requires past tense for completed work. The Catalog shows Ars Futura ending Jul 2026 but bullets at [portfolio.ts:135-137](../../src/catalog/portfolio.ts) read "I build", "I work", "I review". Change tense only - not biography, dates, or claims.
- **P03 Partial** - [accessibility.spec.ts:4-10](../../tests/e2e/accessibility.spec.ts) says "every screen" but scans only the EcoBuiltConnect case study, not ArtisanConnect or RushUploads.
- **P04 Missing source** - issue list is empty; ADR/glossary/standards/testing docs are the current contract. Record and use the governing source when supplied; no invented product work.
